# 1.5.0 Public

1. 更新 ESPHome 到 2026.3.2 （详见<https://esphome.io/changelog/2026.3.0/>）
2. **支持外部自定义应用程序**（需要 SD 卡）。
   1. 创建一个名为 `opt` 的文件夹，并放在 SD 卡的根目录下。
   2. 想一个包名，并创建 `opt/<你的包名>` 文件夹。包名格式为 `aa.bb.cc`。
   3. 在 `opt/<你的包名>` 文件夹下创建 `main.lua`，并编写你的应用程序。
   4. 重启设备，你的应用程序就会显示在主页面。
   5. 你可以在主界面通过点击应用程序图标来启动。
   6. 更多信息请参阅开发者文档/自定义应用程序。
3. 支持桌面图标自定义布局。长按某一图标来调整。
4. 支持启用屏幕反色功能。
5. 联系人支持设置特别关心。（暂时无用）
6. 优化了 Heap 占用。
