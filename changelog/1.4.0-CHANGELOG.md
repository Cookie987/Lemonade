# 1.4.0 Public

1. 更新 ESPHome 到 2026.3.0 （详见<https://esphome.io/changelog/2026.3.0/>）
2. 支持了联系人存储（设备端）
3. 显示组件和 LVGL 使用 DMA 减轻 CPU 传输负担
4. 支持了电池电量估计
5. 优化了部分文本的表述
6. 电源管理优化：
   - 现在，屏幕关闭时会彻底关闭屏幕而不是只关闭背光
   - ST7789V 显示芯片也将同步关闭
   - 优化了秒表的功能实现
   - CPU 最低频率调整至 20MHz
   - 支持了动态锁，无操作 30s 后将自动进入节能模式
   - 息屏、节能模式时降低主循环频率
   - 其余来自 ESPHome 2026.3 的优化
