# 1.4.3 Public

## 1.4.3

1. 支持了 Lua 解释器，目前仅支持开机时运行 SD 卡根目录下的 `init.lua` 文件。
2. 在更多地方增加了小红点提示。
3. MQTT 连接成功时会显示一条通知。
4. 优化系统更新时的提示文本。
5. 修复了给别人发消息会串到自己聊天框的问题。
6. 优化了拼音输入法，支持一次打两个字，优化了显示顺序。

## 1.4.2

1. 增加了系统更新之后提示更新成功的功能。
2. 移动 LVGL 缓冲区到 PSRAM。（这可能会降低性能）
3. 修复了自己在网页端发布的消息不同步的问题。
4. 修复了聊天页面返回按钮漂移的问题。
5. 优化了系统更新的部分文本的表述。

## 1.4.1

1. 修复了广场消息重启后会重复的问题。

## 1.4.0

1. 更新 ESPHome 到 2026.3.1 （详见<https://esphome.io/changelog/2026.3.0/>）
2. 修复了键盘已展开情况下再次单击输入框会重复播放动画的 bug。
3. 支持了联系人存储（设备端），优化了私聊逻辑。
4. 私聊和广场将在设备内存储 100 条聊天记录。
5. 拆分声音设置到一个独立页面。
6. 显示组件和 LVGL 使用 DMA 减轻 CPU 传输负担。
7. 支持了电池电量估计。
8. 优化了堆内存占用。
9. 优化了部分文本的表述。
10. 电源管理优化：
        - 现在，屏幕关闭时会彻底关闭屏幕而不是只关闭背光；
        - ST7789V 显示芯片也将同步关闭；
        - 优化了秒表的功能实现；
        - CPU 最低频率调整至 20MHz；
        - 支持了动态锁，无操作 30s 后将自动进入节能模式；
        - 息屏、节能模式时降低主循环频率；
        - 其余来自 ESPHome 2026.3.0~1 的优化。
