# 1.2.0 Public

1. 更新 ESPHome 到 2026.2.1 （详见<https://esphome.io/changelog/2026.2.0/>）

2. IoT系统更改。现在，请使用 <https://iot.cookie987.top> 进行设备管理和聊天。
3. 聊天App，目前支持频道和私聊消息，及云端聊天记录保存。
4. 构建了通知系统，支持弹窗通知与主页小红点。
5. 电源管理优化：

   - 现在，息屏时会关闭 I2C、SPI 等外设以节省电源
   - 亮屏时会锁定外设总线频率到 80MHz 并不进行 light_sleep。这可能会影响亮屏续航时间。

6. MQTT 使用 TLS 保护数据安全
7. NTP 服务器改为使用域名
8. 修复了状态栏 WiFi 图标更新不及时的 bug
