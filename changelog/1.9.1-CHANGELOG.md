# 1.9.1 Public

## 1.9.1

### 新增功能

1. 新增崩溃日志捕获与显示功能，可在系统设置中查看上次异常退出信息。
2. 新增 NimBLE 蓝牙支持，提供 BLE 广播能力。
3. 新增 WebSocket 客户端组件，支持自动重连和消息回调。
4. Lua 运行时新增 `media_player` 全局 API，支持播放、暂停、停止、音量控制等操作。
5. Lua 运行时新增 `fs` 文件系统 API，支持 `exists`、`isdir`、`listdir` 操作。
6. 新增内置音乐播放器应用（`com.lemonade.music`），支持播放 SD 卡 `/Music` 目录中的本地音乐文件。
7. 新增 3.2 英寸屏幕音频硬件支持（ES8311 DAC + I2S 输出）。
8. 所有内置 Lua 应用现已支持 3.2 英寸屏幕硬件平台。
9. 新增 Lua 应用开发文档、API 参考和应用商店打包规范。
10. 更新 ESPHome 到 2026.6.2 （详见<https://esphome.io/changelog/2026.6.0/>）。

### 改进

1. 优化 PSRAM 内存分配策略，回退到 SRAM 时不再静默失败，提升系统稳定性。
2. 优化 SPIRAM 配置，预留内部内存以减少系统波动。
3. 降低计时器显示刷新频率，减少 UI 资源占用。
4. 计时器状态不再持久化到 Flash，增强稳定性。
5. 优化消息界面操作覆盖层的执行顺序。
6. 优化 LVGL 标签文本空值处理。
7. 其他已知问题修复。
